# 🚀 Руководство по развертыванию SamuraiWorld на NixOS (Моноблок 2011 года)

Это самое легкое, быстрое и надежное решение для хостинга проекта на старом оборудовании через Docker Compose.

---

## 🛠️ Шаг 1. Включить Docker в NixOS

На моноблоке откройте файл конфигурации системы:
```bash
sudo nano /etc/nixos/configuration.nix
```

Добавьте следующие строки:
```nixos
# Включаем Docker и разрешаем автозапуск контейнеров при загрузке ПК
virtualisation.docker.enable = true;

# (Опционально) Добавляем своего пользователя в группу docker
users.users.YOUR_USERNAME.extraGroups = [ "docker" ];
```

Сохраните файл и примените конфигурацию:
```bash
sudo nixos-rebuild switch
```

---

## 📁 Шаг 2. Скопировать проект и запустить

Перейдите в папку с проектом `minecraft-server-site`:
```bash
cd ~/minecraft-server-site
```

Запустите сборку и запуск проекта в фоновом режиме:
```bash
docker compose up -d --build
```

---

## 🌐 Шаг 3. Как открывать сайт

1. **В локальной сети (дома):**
   Откройте IP-адрес вашего моноблока в браузере (например `http://192.168.1.50`).
2. **Из внешнего интернета (для друзей и игроков):**
   * **Вариант А (Бесплатный и самый легкий без белого IP — Cloudflare Tunnel):**
     Установите `cloudflared` через NixOS: `environment.systemPackages = [ pkgs.cloudflared ];`
     Запустите бесплатный туннель к порту 80, и Cloudflare даст вам SSL-сертификат (HTTPS) и домен за 1 минуту!
   * **Вариант Б (С белым IP):**
     Пробросьте порт `80` (HTTP) на роутере к IP-адресу вашего моноблока.

## 🔍 Полезные команды управления

```bash
# Проверить статус контейнеров
docker compose ps

# Посмотреть логи бэкенда или фронтенда
docker compose logs -f

# Перезапустить проект
docker compose restart

# Остановить проект
docker compose down
```
